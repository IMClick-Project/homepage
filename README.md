# IMClick-Project

IMClick-Project es una página web desarrollada con **HTML, CSS y JavaScript** como proyecto en el curso **"Course Frontend" de DEV.F**. El objetivo del proyecto es presentar una iniciativa personal para compartir recursos académicos de manera clara, accesible y práctica.

El proyecto está enfocado en tres áreas principales:

- Informática
- Matemáticas
- Ingeniería Química

## Descripción del proyecto

La página funciona como una **landing page educativa** donde se presentan las áreas de conocimiento, los tipos de recursos que se planean desarrollar y una sección de contacto para personas interesadas en el proyecto o en colaborar.

El diseño busca ser **claro, moderno y fácil de navegar**, utilizando HTML semántico, layouts con **Flexbox y Grid**, y estilos consistentes basados en una paleta de colores propia.

El sitio incluye secciones como:

- **Hero section** con animaciones CSS
- **Áreas de estudio** con tarjetas informativas
- **Recursos** disponibles en el proyecto
- **About me** con carrusel de imágenes
- **Contacto** con redes y formulario
- **Selector de idioma (ESP / ENG)**

La página es **responsive**, adaptándose a dispositivos móviles mediante media queries.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (DOM manipulation)
- Bootstrap Icons
- GitHub Pages

## Características

- Diseño responsive
- Animaciones CSS en la sección principal
- Carrusel de imágenes en la sección *About me*
- Navegación adaptable a dispositivos móviles
- Versión en **español e inglés**
- Organización clara del contenido académico

## Publicación

La página está publicada utilizando **[GitHub Pages](https://imclick-project.github.io/homepage/)**.

## Objetivo del proyecto

Este proyecto busca servir como una plataforma inicial para compartir contenido educativo relacionado con **matemáticas, informática e ingeniería química**, así como funcionar como práctica de desarrollo front-end y diseño web.
